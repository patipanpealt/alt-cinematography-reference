# A Cinematography Reference

Static site. No framework, no build step at runtime — plain HTML + CSS + one small JS file.

## Run locally
```
python3 build/serve.py 4173
```
then open http://localhost:4173

## Layout
```
site/                deployable — copy this folder anywhere static
  index.html         generated by build/build.py
  styles.css         hand-written
  app.js             lightbox, back-to-top, nav active state
  assets/
    logo/            ALT mark, orange + white
    shots/    (10)   shot-size photographs
    angles/   (10)   camera-angle photographs
    examples/  (5)   composition examples
build/
  build.py           regenerates site/index.html from ../content.json
  _glyphs.json       the 41 inline diagram SVGs, lifted from the source page
  _logo-inline.html  the ALT mark, prepared for inlining
  serve.py           the local static server
```

## Editing content
Copy lives in `../content.json`. Edit it, then:
```
python3 build/build.py
```
The builder asserts the output carries no third-party brand name and fails the build if it does.

## Layout language
Chrome and layout follow `../Design Reference/Layout & Design/Color-04.jpg`:
the whole page sits in a rounded panel floating on a warm-black ground, the nav is a
floating capsule, each section opens with an outline chip and a two-tone headline whose
alignment alternates left/right down the page, and the Lighting section is a
cream / orange / dark card checkerboard.

## Notes
- The ALT mark pairs solid shapes with outlined counter-shapes. Its strokes are authored
  in a 960-unit viewBox, so at UI sizes they scale below a pixel and disappear, leaving the
  mark looking broken. It is therefore inlined (not an `<img>`) and its strokes use
  `vector-effect: non-scaling-stroke`.
- Photo boxes declare `aspect-ratio`, so lazy-loaded images cause no layout shift.
- The photo cards carry Color-04's circular corner button, but here it is a real control:
  it opens the full image, which is what clicking the thumbnail already does.
- Back-to-top keys off an IntersectionObserver on the hero rather than a measured
  threshold: an earlier version cached the hero height before the webfonts landed and
  the button never appeared. Nav highlighting reads `offsetTop` live on each scroll —
  cached offsets went stale, and an IntersectionObserver band missed sections on fast
  jumps.
- Cream and orange card fills are used only in Lighting, whose items are pure text. The
  other sections hold dark photographs and orange-on-dark diagrams, which a cream fill
  would fight.
